# init_files_variables_and_expansions: scripts de archivos de inicialización, variables y expansiones
- 0-alias: crea un alias ls con valor rm -f *
- 1-hello_you: imprime hello seguido del usuario actual de Linux
- 2-path: añade /action al final de la variable PATH
- 3-paths: cuenta el número de directorios no vacíos en la variable PATH
- 4-global_variables: lista las variables de entorno
- 5-local_variables: lista todas las variables locales, de entorno y las funciones
- 6-create_local_variable: crea la variable local BEST con valor School
- 7-create_global_variable: crea la variable global BEST con valor School
- 8-true_knowledge: imprime la suma de 128 con el valor de la variable TRUEKNOWLEDGE
- 9-divide_and_rule: imprime el resultado de POWER dividido por DIVIDE
- 10-love_exponent_breath: imprime BREATH elevado a la potencia LOVE
- 11-binary_to_decimal: convierte el número binario de la variable BINARY a base 10
- 12-combinations: imprime todas las combinaciones de dos letras minúsculas excepto oo
